# Indio Voice

The narration is generated by Chatterbox Multilingual (ResembleAI, weights from Hugging Face), which
speaks in the voice of a short reference recording. Tagalog is not one of its official languages;
Malay mode reads Tagalog spelling clearly, so that is what the scripts use. Expression comes from
directing each sentence, the way a voice director would, not from one flat setting for the whole
script.

Be straight with the user about limits: this gives a natural, varied read in their voice, but it
cannot laugh, sigh or truly whisper on cue, and you cannot hear the result. Always run the check in
step 4 and ask the user to listen before they post.

## 1. Narrator sample (once)
Needs 15–25 s of the narrator alone, no music. If the only source is a finished video with music:
`python scripts/prep_reference.py video.mp4 narrator.wav` separates the voice and trims the
silences. Only clone a voice the user owns or has permission to use. Keep the sample out of public
repos; pass its path as `HI_VOICE_REF`.

## 2. Direct the script
Put a tag at the start of any sentence that should not be read in the default storytelling tone.
A tag lasts for that one sentence. Use them on beats, not everywhere — if every line is
`[excited]`, nothing is.

| Tag | Use it for |
|---|---|
| `[excited]` | the hook, reveals, punchlines |
| `[playful]` | jokes, slang lines, asides to the viewer |
| `[serious]` | dates, names, official acts |
| `[dramatic]` | turning points, "pero..." lines |
| `[suspense]` | build-up before a reveal (slower, quieter) |
| `[whisper]` | secrets and rumours (soft and slow — an approximation, not a true whisper) |
| `[somber]` | losses, endings |
| `[triumphant]` | victories |
| `[curious]` | questions to the viewer |
| `[warm]` | closings, thank-yous |
| `[slow]` / `[fast]` | pace only; combine with one tone tag |
| `[pause 0.8]` | extra silence, in seconds, before the sentence |

Example: `[suspense] May ulat pa nga na baka alam na ng mga Kastila ang plano. [curious] So bluff ba talaga ang nagpanalo?`

Spelling matters more than tags. The model reads letters phonetically, so respell anything a
Tagalog reader would not sound out: years and numbers in words, English words the way they are
said ("plot twist" → "plat twist"), Spanish names ("José" → "Hose", "c" → "k" or "s"). The
History Indio repo keeps these in `pipeline/respell.json`; add to it as you go.

## 3. Generate
`python scripts/voice.py sentences.json narrator.wav out.wav timings.json`
`sentences.json` is a list of `{"text", "say", "style", "pause"}`; in the History Indio repo
`pipeline/make_sentences.py script.txt sentences.json` builds it from the tagged script. The script
writes one wav plus the start and end time of every sentence, which the video is cut to. On CPU it
runs at about four times real time, so a 3-minute script takes 12–15 minutes. Needs the
`chatterbox-tts` package (and `setuptools<81` on Python 3.12+ for its watermark module — keep the
watermark; it marks the audio as AI-generated).

## 4. Check
`python scripts/check_voice.py out.wav timings.json` transcribes each sentence with Whisper and
prints how many words matched. Regenerate sentences under about 70% (fix the spelling first, or
change the seed). The score shows the words are clear; it says nothing about how natural it
sounds, so say that when delivering.

## When it still sounds off
- Flat: add tone tags on the beats and raise contrast between neighbours (a `[suspense]` line before an `[excited]` one).
- Rushed or slurred: shorten the sentence, or split it in two.
- Wrong word: respell it.
- Still not right: the best voiceover is the user's own recording; the video is cut to whatever audio it is given.
