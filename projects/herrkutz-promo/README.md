# Herrkutz Barbershop — 30s Promo

`HerrkutzPromo30.mp4` — 30.0s vertical (720×1280) promo cut from one raw 34.7s handheld take.

Structure: hook → prep → the cut → arrival → the shop → reveal → logo card. 29 shots, cut on a 120 BPM grid.

- `scripts/edl.py` — edit decision list (output time, duration, source in-point, speed).
- `scripts/render.py` — trims/concats the source clips with ffmpeg.
- `scripts/synth.py` — original synthesized beat and SFX (clipper hum, razor scrape, whoosh, boom, riser).

Audio: original 120 BPM beat + synthesized SFX + the clip's real room audio. No voice cloning.
