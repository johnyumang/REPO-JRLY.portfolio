# Episode 27 facts: the Yamaha YZF-R1, 1998

Checked on 2026-11-20. R = https://en.wikipedia.org/wiki/Yamaha_YZF-R1 (page text read to character 100000 of 101610).

| Fact | Value | Source |
|---|---|---|
| Builder, when | Yamaha Motor Company; "Yamaha launched the YZF-R1 in 1998." The page gives no factory location and names no designer | R |
| What was new | engine redesigned from the Genesis engine to be more compact; the gearbox input shaft was raised so the output shaft could sit beneath it, making a "stacked gearbox" that other makers later copied; the shorter engine allowed a shorter wheelbase, an optimized centre of gravity and a longer swingarm | R |
| Part 1: engine | "998 cc (60.9 cu in), liquid-cooled, 20-valve, DOHC, inline four-cylinder"; bore 74 mm x stroke 58 mm; compression 11.8:1 | R |
| Part 2: carburettors | four 40 mm Keihin CV carburettors | R |
| Part 3: gearbox | the "stacked gearbox" (input shaft raised, output shaft beneath it) | R |
| Part 4: front fork | 41 mm KYB upside-down fork | R |
| Power | 150 hp (110 kW) at the crank, citing 1997 Cycle World | R |
| Weight | 190.1 kg (419 lb) dry (Cycle World, 1999) | R |
| Tyre sizes | 120/70-ZR17 front, 190/50-ZR17 rear (table; the column for 1998 is unclear, so shown only as "17-inch wheels implied") | R |
| Length | 2,035 mm (80.1 in) | R |
| Top speed | 270 km/h (168 mph) per Motorcycle Consumer News; Cycle World 1999 gives 170 mph (270 km/h) | R |
| Rider moment | none found: the page records no 1998 race win or rider milestone. Only: it "won five Macau Grand Prix races between 1999 and 2013" | R |
| What came next | 2000-2001: dry weight reduced to 414 lb (188 kg); 2002-2003: fuel injection, titanium exhaust and the newly developed Deltabox frame; YZF-R6 (600 cc) arrived in 1999 | R |
